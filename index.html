Section 1 · Rendering Pipeline & Lighting Architecture (BlackSpace-Style)

Non-goals: no lightmap bakes, no screen-space-only reflections. Every light transport path below is evaluated or invalidated at runtime so time-of-day, weather, and destruction stay consistent.

1.1 Global Illumination — Surfel Radiance Cache + SDF fallback

Primary GI is a world-space surfel radiance cache: surfels spawned from the G-buffer (position, normal, albedo) at ~1/4 resolution, each storing irradiance + mean normal + validity radius. Surfels live in a spatial hash grid (cell ≈ 0.5 m near-field, coarser far-field), accumulate multi-bounce diffuse via temporal injection, and are sampled per-pixel with bilateral weighting. A coarse SDF/volume probe grid backs regions with no surfel coverage (sky, far interiors).

Frame pipeline (per frame, async compute where noted)
┌──────────┐  ┌──────────────┐  ┌────────────────┐  ┌──────────────┐
│ G-Buffer │─▶│Surfel spawn/ │─▶│Irradiance      │─▶│Per-pixel     │
│ 1/4 res  │  │invalidate    │  │inject+temporal │  │gather+bilat. │
└──────────┘  └──────────────┘  └────────────────┘  └──────────────┘
                     │ sun/moon dir │ sky SH │ interior bounce (2-3 taps)
                     ▼              ▼        ▼
              ┌──────────────────────────────────┐
              │ SDF probe grid (fallback/sky)    │
              └──────────────────────────────────┘
  • Dynamic sun/moon: directional radiance re-injected every frame; surfel validity includes an angular term so a rotating sun invalidates stale surfels in O(changed) rather than full flush.
  • Multi-bounce interiors: 2 injection bounces at half rate (every 2nd frame, checkerboarded) + 3rd bounce approximated from the SDF probe grid. Cost ≈ 1.2–1.8 ms @1440p on current-gen GPU.
  • Math: outgoing diffuse L_o = (ρ/π) · Σ_k w_k · E_k, weights w_k = max(0, n·n_k) · falloff(|p−p_k|/r_k) · validity_k, normalized over the surviving kernel.

1.2 Hybrid Ray-Tracing & Reflections

Reflections resolve in three tiers, chosen per-pixel by roughness and distance — this removes SSR disocclusion holes while bounding BVH cost:

  1. Near field (0–150 m): hardware BVH ray trace (DXR/Vulkan RT) for meshes + skinned characters, one bounce, importance-sampled by GGX lobe.
  2. Far field (>150 m) + water: analytic SDF ray march against the global distance field (city SDF streamed with sectors); water adds a Gerstner-normal perturbation before marching.
  3. Rough/glossy: prefiltered surfel/SDF radiance replaces explicit rays above roughness ≈ 0.35 (split-sum style).
roughness ──▶ sharp? ──yes──▶ dist<150m? ──yes──▶ BVH trace (1 bounce)
     │                       │                    └─no──▶ SDF march
     └─no (rough)──▶ surfel/SDF prefiltered sample (no ray)

1.3 Atmospherics & Volumetrics

Physically based sky: Preetham/Hosek-style analytic core upgraded with per-frame sun/moon luminance integration (extraterrestrial illuminance × transmittance), photon mean-free-path from a height-graded extinction table, and a 3D froxel fog volume (e.g. 160×90×64 over the view frustum) for fog, morning mist, muzzle smoke, and dust. Mist density is advected by the same wind field used for foliage (§2) and displaced by entity capsules: each active character/vehicle writes a short-lived velocity splat into the fog volume (decaying over ~1.5 s), so running through mist parts it. Temporal reprojection + bilateral upsample keep volumetrics ≈ 1 ms.

Section 2 · Environmental Physics & Dynamic Material Interaction

2.1 Wind & Foliage Simulation

One authoritative procedural wind field W(p,t) sampled on CPU (physics/AI/audio) and GPU (vertex shaders) from identical constants: 3 layered noises (synoptic gust ~100 m wavelength, street-canyon turbulence ~10 m, leaf flutter ~1 m) + gust fronts advected along a prevailing direction + occlusion masks from buildings. Vegetation bends in the vertex shader as offset = W(p,t) · heightWeight · flexibility; forests beyond ~300 m swap to camera-facing imposters that sample the same field per-instance so the canopy keeps moving at distance. Urban props (awnings, flags, papers) sample the street-canyon layer. See the WindManager starter code for the exact CPU/GPU contract.

2.2 Destruction & Cloth Physics

A modular component model keeps cloth, fracture, and particles on separate budgets but one job graph:

  • Cloth (clothing, vehicle covers, awnings): PBD/XPBD solver, 2–4 substeps, distance + bending constraints; characters run reduced particle sets (300–800) with skinned kinematic pins; wind field feeds external forces directly.
  • Shatterable glass: pre-authored Voronoi fracture patterns; on impact, shards become rigid bodies with a 3–5 s lifetime, then demote to GPU-only debris.
  • Dynamic debris & reactive particles: pooled rigid-body debris (cap ~512 active) + GPU particle fields (sparks, dust, glass glints) parameterized by impact energy and surface material ID from the G-buffer.
Impact event ─▶ material table ─┬─▶ cloth impulse (if fabric)
                                 ├─▶ fracture pattern (if glass/brittle)
                                 └─▶ debris pool + particle burst (energy-scaled)

Section 3 · Open-World Streaming & Vehicle/Pedestrian Simulation (GTA-Style)

3.1 Streaming & LOD Framework

World is tiled into sectors (~128 m) with ring priorities around the camera + predicted movement vector. A dedicated streaming thread pool (I/O + decompress + GPU upload queues) pages geometry, SDF bricks, traffic splines, and pedestrian nav nodes. LOD policy: hero meshes near, proxy/imposter mid, SDF-only far. Hitch guards: frame-time-budgeted uploads, predictive prefetch along velocity, and a fallback low-LOD hold when I/O stalls — never a blocking load on the game thread.

Game thread: camera+velocity ─▶ priority rings ─▶ request queue
Streaming threads: I/O ─▶ decompress ─▶ GPU upload (budgeted/frame)
GPU: sector resident? ─yes─▶ draw LOD(n)   ─no─▶ hold coarse LOD + prefetch

3.2 Vehicle Physics Bridge

Arcade-credible but telemetry-driven handling:

  • Contact: raycast wheel-ground model (4–6 rays/vehicle) returning compression, surface normal, surface material.
  • Suspension: spring-damper per corner with telemetry (travel, load, bottoming events) feeding audio + camera shake + damage.
  • Tires: Pacejka-lite friction ellipse keyed by surface coefficient (asphalt/wet/dirt/sidewalk) + load sensitivity + slip angle; dynamic center-of-mass shifts with passengers, cargo, and fuel.
  • Bridge: physics core steps at fixed 120 Hz, render interpolation at display rate; traffic AI consumes the same handling interface with simplified inputs so ambient cars behave like the player car.

3.3 Pedestrian / Traffic Simulation

Pedestrian AI nodes and traffic splines stream with sectors; LOD'd crowd (full behavior near, flow-field far). Time-sliced updates (e.g. 1/4 of agents per frame) with interest-based priority near missions, combat, or the camera.

Section 4 · Starter Code Implementation

Two heavily commented, dependency-free C++17 snippets: the per-pixel surfel lighting evaluator and the wind/foliage manager whose constants must match the vertex shader. Both are structured for a multi-threaded game loop (job-system friendly, no hidden allocations in the hot path).

4.1 Surfel Radiance Cache — Real-Time Lighting Evaluator

// SurfelLighting.h — BlackSpace-style dynamic GI evaluator (C++17, no deps).
// Contract: surfels are maintained by an async compute/job pass; this
// evaluates per-pixel diffuse bounce under shifting sun/moon without bakes.
#pragma once
#include <cstdint>
#include <cmath>

struct Vec3 { float x, y, z; };
inline Vec3 operator+(Vec3 a, Vec3 b){return{a.x+b.x,a.y+b.y,a.z+b.z};}
inline Vec3 operator-(Vec3 a, Vec3 b){return{a.x-b.x,a.y-b.y,a.z-b.z};}
inline Vec3 operator*(Vec3 a, float s){return{a.x*s,a.y*s,a.z*s};}
inline float Dot(Vec3 a, Vec3 b){return a.x*b.x+a.y*b.y+a.z*b.z;}
inline float Length(Vec3 v){return std::sqrt(Dot(v,v));}

// One cached bounce sample in world space.
struct Surfel {
    Vec3  position;    // world-space anchor
    Vec3  normal;      // geometric mean normal of contributing pixels
    Vec3  irradiance;  // multi-bounce diffuse irradiance E (lux-like)
    float radius;      // validity radius (m); grows in flat regions
    float validity;    // [0,1] temporal confidence; sun motion decays it
    uint32_t lastTouchFrame;
};

// Time-of-day lighting state, refreshed once per frame on the game thread.
struct DayPhase {
    Vec3  sunDir;        // normalized, points TOWARD the sun
    Vec3  sunColor;      // sun radiance (includes elevation dimming)
    Vec3  moonDir;
    Vec3  moonColor;     // ~0 at day; dominates at night
    Vec3  skyAmbient;    // SDF-probe fallback ambient
    float sunAngularChange; // radians since last frame (drives invalidation)
};

// --- Tuning ---------------------------------------------------------------
constexpr int   kGatherRays   = 8;    // surfels sampled per pixel
constexpr float kBaseRadius   = 0.6f; // m, near-field surfel spacing
constexpr float kMaxRadius    = 3.0f; // m, far/flat-region cap
constexpr float kAngleWeight  = 2.0f; // normal-similarity sharpness

// Bilateral kernel: normal agreement x distance falloff x confidence.
inline float SurfelWeight(const Vec3& p, const Vec3& n,
                          const Surfel& s) {
    Vec3  d    = p - s.position;
    float dist = Length(d);
    if (dist > s.radius * 2.0f || s.validity <= 0.0f) return 0.0f;
    float nAlign = Dot(n, s.normal);
    if (nAlign <= 0.0f) return 0.0f;              // backface: no bounce
    float falloff = 1.0f - dist / (s.radius * 2.0f);
    return std::pow(nAlign, kAngleWeight) * falloff * falloff * s.validity;
}

// Per-pixel diffuse bounce: L_o = (rho/pi) * E_gathered.
// `fetch(i)` maps gather tap i -> surfel (hash-grid lookup in real engine;
// a flat ring buffer here keeps the snippet dependency-free).
// Thread-safety: read-only over surfels; run one call per pixel in jobs.
template <typename FetchFn>
Vec3 EvaluateSurfelBounce(const Vec3& albedo, const Vec3& fragPos,
                          const Vec3& fragNormal, FetchFn&& fetch) {
    Vec3  acc{0, 0, 0};
    float wSum = 0.0f;
    for (int i = 0; i < kGatherRays; ++i) {
        const Surfel& s = fetch(i);
        float w = SurfelWeight(fragPos, fragNormal, s);
        acc  = acc + s.irradiance * w;
        wSum += w;
    }
    if (wSum < 1e-4f) return {0, 0, 0};           // caller adds SDF fallback
    Vec3 e = acc * (1.0f / wSum);                 // normalized irradiance
    constexpr float kInvPi = 0.3183099f;
    return {albedo.x * e.x * kInvPi,               // Lambert: rho/pi * E
            albedo.y * e.y * kInvPi,
            albedo.z * e.z * kInvPi};
}

// Per-frame maintenance (jobified over surfel tiles): decay surfels the
// moving sun/moon invalidated, so time-of-day shifts cost O(changed).
inline void InvalidateForTimeOfDay(Surfel* surfels, int count,
                                   const DayPhase& phase, uint32_t frame) {
    // Wider sun swing => harsher confidence cut. Moon uses same path at night.
    float cut = 1.0f - fminf(phase.sunAngularChange * 8.0f, 0.9f);
    for (int i = 0; i < count; ++i) {
        surfels[i].validity *= cut;
        surfels[i].lastTouchFrame = frame;
    }
}

4.2 Procedural Wind & Foliage Interaction Manager

// WindManager.h — one wind field for CPU + GPU (C++17, no deps).
// The GLSL/HLSL vertex snippet below MUST use the same constants, or
// foliage will disagree with physics/audio about wind direction.
#pragma once
#include <cmath>

struct Vec3w { float x, y, z; };

struct WindParams {
    Vec3w prevailingDir = {0.8f, 0.0f, 0.6f}; // normalized XZ wind rose dir
    float gustSpeed     = 6.0f;   // m/s advection of gust fronts
    float gustStrength  = 2.2f;   // m/s peak gust amplitude
    float turbulence    = 0.8f;   // street-canyon layer gain
    float flutter       = 0.35f;  // leaf-scale high-frequency gain
    float time          = 0.0f;   // seconds, advanced once per frame
};

// Cheap deterministic value-noise stand-ins (hash-based, no tables, so the
// GPU copy stays bit-similar). Replace with your noise LUT if available.
inline float Hash1(float n){ return fmodf(sinf(n * 127.1f) * 43758.5453f, 1.0f); }
inline float VNoise(float x){
    float i = floorf(x), f = x - i;
    float u = f * f * (3.0f - 2.0f * f);
    return Hash1(i) * (1.0f - u) + Hash1(i + 1.0f) * u; // [0,1)
}

class WindManager {
public:
    explicit WindManager(const WindParams& p = {}) : params_(p) {}

    // Advance once per frame on the game thread (NOT per job).
    void Update(float dt) { params_.time += dt; }

    // Sample the full spatial wind vector at world position p (m/s).
    // Job-safe: reads params_ atomically-refreshed per frame; no writes.
    Vec3w Sample(float px, float py, float pz) const {
        const float t = params_.time;
        // Layer 1: synoptic gust front (~100 m), advected with prevailing dir.
        float front = VNoise((px * params_.prevailingDir.x
                            + pz * params_.prevailingDir.z) * 0.01f
                            - t * params_.gustSpeed * 0.02f);
        float gust = (front - 0.5f) * 2.0f * params_.gustStrength;
        // Layer 2: street-canyon turbulence (~10 m).
        float turb = (VNoise((px + pz) * 0.1f + t * 0.7f) - 0.5f)
                   * 2.0f * params_.turbulence;
        // Layer 3: leaf flutter (~1 m, height-graded by py in shader).
        float flut = (VNoise((px * 3.1f + py * 1.7f + pz * 2.3f) + t * 3.0f)
                   - 0.5f) * 2.0f * params_.flutter;
        float s = 1.0f + gust + turb;             // bulk flow multiplier
        return {params_.prevailingDir.x * s + flut,
                flut * 0.4f,                      // slight vertical lift
                params_.prevailingDir.z * s - flut};
    }

    const WindParams& params() const { return params_; }

private:
    WindParams params_;
};

/* --- GPU twin (GLSL): paste into the foliage vertex shader ---------------
uniform vec3 uWindDir;   // = prevailingDir (normalized)
uniform float uTime;     // = WindManager time
uniform float uGust;     // = gustStrength
uniform float uTurb;     // = turbulence
uniform float uFlutter;  // = flutter

vec3 windSample(vec3 worldPos) {
    float front = fract(sin(dot(vec2(
        (worldPos.x * uWindDir.x + worldPos.z * uWindDir.z) * 0.01
        - uTime * 0.12, 1.0), vec2(127.1, 311.7)) * 43758.5453);
    float s = 1.0 + (front - 0.5) * 2.0 * uGust
                + (fract(sin(dot(vec2((worldPos.x + worldPos.z) * 0.1
        + uTime * 0.7, 1.0), vec2(127.1, 311.7)) * 43758.5453)) - 0.5)
        * 2.0 * uTurb;
    return vec3(uWindDir.x * s, 0.0, uWindDir.z * s);
}
// usage: transformed += windSample(worldPos)
//        * pow(uv.y, 1.5)   // heightWeight: roots pinned, tips free
//        * uFlexibility;    // per-species stiffness
// Distant imposters sample windSample() once per instance on the CPU and
// pass it as instance data, so the whole forest breathes in phase.
