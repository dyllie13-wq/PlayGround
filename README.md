# Call to Defense — modern-era total warfare

A Total War–like 3D strategy game for desktop browsers, built from the
*Modern Era Total War Design Document*: a grand-strategy **campaign layer**
on a living 3D globe married to real-time **tactical battles** with
combined-arms battlegroups.

- **Strategic pillar** — 10-region globe (NASA imagery), logistics & munitions
  economy, defense-industrial base, escalation meter, Fog-of-War 2.0
  (satellites / cyber / recon), and hybrid warfare: cyberattacks, proxy
  militias, disinformation, satellite sweeps.
- **Tactical pillar** — MBTs, IFVs, infantry, SHORAD, long-range SAM, recon
  UAVs, EW jamming vehicles, supply trucks; sensor-vs-concealment detection,
  SEAD strikes, MLRS barrages, loitering munitions, smoke screens,
  destructible urban blocks that become rubble cover, and two capture plazas.
- **Command view** — cinematic 3D ↔ NATO blue-force tracker (`T`), live UAV
  thermal PiP feed, phase flow Recon → SEAD & Shaping → Assault → Clearance.
- **Tech** — Three.js + Vite. Six CC-licensed Sketchfab vehicle models
  (see `ATTRIBUTION.md`), procedural terrain/audio, no external runtime assets.

Run locally: `npm install && npm run dev` (or `npm run build` for `dist/`).
